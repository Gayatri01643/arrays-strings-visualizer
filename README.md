# Arrays and Strings Visualizer

A web page that shows common array and string operations step by step.

Array: add, insert, delete, search, bubble sort, reverse.
String: reverse, palindrome check, count vowels, find substring, character frequency.

Built with HTML, CSS, JavaScript and a Python backend that saves run history.

## How to run
1. Install Python.
2. Put index.html and server.py in the same folder.
3. Run: python server.py
4. Open http://localhost:3000
